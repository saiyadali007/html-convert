# Design Reference Directory

This directory contains the original design specifications and visual references for the Debuggers Studio website rebuild.

## Contents
- **`design.md`**: Complete design token extraction, component census, typography scale, colors, spacing, and responsive behavior extracted directly from the live WordPress website (https://debuggersstudio.com/).
- **`reference/homepage.png`**: Full-page reference screenshot of the original homepage. All future implementation must visually align with this reference.
